Giới thiệu bản thân

Tôi là sinh viên ngành Kỹ thuật phần mềm và đang tìm hiểu quy trình phát triển, kiểm thử và triển khai phần mềm.

Kỹ năng đang học

  • HTML và CSS để xây dựng giao diện website.
  • Git và GitHub để quản lý mã nguồn.
  • GitHub Actions để tự động hóa các công việc.
  • CI/CD và GitHub Pages để triển khai website.

Mục tiêu

Hoàn thành quy trình CI/CD cơ bản, triển khai website tự động và sử dụng Lighthouse để đánh giá chất lượng website.
